Khối 1 — Giới thiệu

Đây là công cụ tự động hoá quy trình lên kế hoạch đi báo PR + guest post (SEO Offpage). Bạn nộp file check TOP từ khoá của dự án, công cụ tự phân tích và trả về danh sách anchor text nên đi offpage, ghép chúng thành từng cụm 2 anchor/bài, rồi chọn domain báo/guest post cụ thể phù hợp ngân sách bạn đặt ra.

Toàn bộ chạy trong trình duyệt của bạn — không có server nào của chúng tôi lưu trữ dữ liệu hay API key bạn nhập.

Quy trình gồm 2 phần rõ rệt, chi phí khác nhau:

Phần miễn phí (Khối 2 bên dưới) — đọc file check TOP, thống kê phân bố thứ hạng theo bộ từ khoá, lọc ra từ khoá nào đáng đầu tư offpage. Đây là các phép tính thuần tuý (đếm, so sánh số), chạy bằng JavaScript ngay trên máy bạn, không gọi tới AI, không tốn phí dù file dài bao nhiêu dòng. Bạn sẽ thấy kết quả ngay sau khi bấm nút, không cần API key.

Phần cần trả phí (Khối 3 bên dưới) — 2 việc còn lại cần AI thật sự "hiểu" nội dung: ghép 2 anchor text vào cùng 1 bài sao cho hợp ngữ cảnh chủ đề, và chọn domain báo/GP đúng lĩnh vực trong giới hạn ngân sách. Việc này bắt buộc phải gọi mô hình AI (Claude), nên bạn cần tự cung cấp API key của mình — chi phí tính theo lượng dữ liệu xử lý mỗi lần chạy, do nhà cung cấp AI thu trực tiếp qua API key của bạn, không qua chúng tôi.

Khối 2 — Thống kê TOP & lọc từ khoá ứng viên

Đầu vào: file check TOP từ khoá (CSV), mỗi file tương ứng 1 bộ từ khoá (BTK).
Đầu ra: bảng thống kê phân bố thứ hạng theo BTK, và danh sách từ khoá đáng đầu tư offpage (kèm lý do) — hiện ngay bên dưới, không cần chờ AI.

Mỗi file check TOP cần có 3 loại thông tin — công cụ tự đoán cột tương ứng dựa trên tên cột, bạn xác nhận hoặc chỉnh lại trong ô chọn cột hiện ra sau khi upload file:
  • Từ khoá — cột chứa từ khoá/anchor text.
  • TOP hiện tại (mới nhất) — thứ hạng hiện tại, không phải cột lịch sử theo ngày (VD nếu có cột "Now" thì đó thường là cột đúng, không phải cột "TOP lên AIO" hay các cột ngày tháng).
  • URL — trang đích của từ khoá.
Các cột khác trong file không bắt buộc, công cụ bỏ qua.

Khối 3 — Ghép cụm anchor & chọn domain theo ngân sách

Đầu vào: kết quả Khối 2 (tự động) + file KPI (tuỳ chọn) cho phần ghép cụm; danh sách domain báo/GP + ngân sách cho phần chọn domain.
Đầu ra: bảng cụm anchor đã ghép, rồi bảng domain báo/GP đã chọn kèm ngân sách, xuất được ra Excel.

Lấy API key tại console.anthropic.com/settings/keys. Key chỉ lưu trong localStorage trình duyệt bạn, gọi thẳng tới Anthropic — không qua server nào của chúng tôi. Đề xuất 3 model tuỳ nhu cầu chi phí/chất lượng:

3a. Ghép cụm anchor text theo chủ đề

Có file KPI, công cụ ưu tiên thêm từ khoá cần đẩy để đạt KPI gần hơn, kể cả khi đã TOP1-10.

3b. Chọn domain báo & guest post theo ngân sách

Nếu bạn đã có sẵn danh sách domain phù hợp, upload CSV ở đây để dùng luôn. Không có thì để trống — công cụ tự lấy bảng giá sống từ Google Sheet chung của công ty.
