Đây là gì?

Công cụ tự động hoá quy trình lên kế hoạch đi báo PR + guest post (SEO Offpage): bạn nộp file check TOP từ khoá + ngân sách, công cụ trả về danh sách anchor text nên đi + domain báo/GP cụ thể nên chọn. Chạy đúng theo quy trình 2 bước:

  1. Bước 1 — Phân tích & đề xuất anchor text. Đọc file check TOP, tìm từ khoá đáng đầu tư offpage, ghép mỗi 2 anchor text thành 1 cụm cho 1 bài (theo đúng logic ngành).
  2. Bước 2 — Chọn domain theo ngân sách. Từ cụm anchor ở bước 1, chọn domain báo/guest post phù hợp lĩnh vực, đúng ngân sách bạn đặt ra.
Miễn phí (chạy trong trình duyệt) Cần API key, có tính phí
Bước 1 Thống kê TOP theo bộ từ khoá, lọc từ khoá đáng đầu tư — tính bằng JS, dù file dài mấy nghìn dòng cũng không tốn phí. Nhận diện đúng cột trong file CSV của bạn (1 lệnh rất nhỏ/file) + ghép cụm anchor theo chủ đề (cần Claude hiểu ngữ cảnh ngành).
Bước 2 Lọc bớt domain rõ ràng không dùng được (Note ghi "tạm dừng"/"dừng bán") — tính bằng JS. Khớp danh mục ngành + chọn domain đúng ngân sách (cần Claude phán đoán ngữ nghĩa).

Chi phí phần "cần API key" tuỳ vào model bạn chọn và độ dài file — công cụ hiện số token ước tính trước mỗi lần gọi để bạn chủ động. Bạn tự trả chi phí này bằng API key của mình, không qua bất kỳ server nào của chúng tôi.

0. API key của bạn

Lấy key tại console.anthropic.com/settings/keys. Key chỉ lưu trong localStorage của trình duyệt bạn, gọi thẳng tới Anthropic — không có server trung gian nào của chúng tôi nhìn thấy key này.

1. File check TOP & đề xuất anchor text

Tương ứng agent seo-offpage-technical.

File check TOP cần gì? Công cụ tự nhận diện 3 cột trong file bạn upload — không cần đặt đúng tên cột, không cần đúng thứ tự cột:
  • Từ khoá — cột chứa từ khoá/anchor text.
  • TOP hiện tại (mới nhất) — thứ hạng hiện tại, không phải cột lịch sử theo ngày. Nếu file có cột tên "Now" hoặc tương đương, công cụ ưu tiên chọn cột đó.
  • URL — trang đích của từ khoá đó.
Các cột khác trong file (Volume, DA, ghi chú...) không bắt buộc — công cụ bỏ qua, không ảnh hưởng kết quả, bạn không cần xoá chúng đi.

Có file KPI thì công cụ sẽ ưu tiên thêm các từ khoá cần đẩy để đạt KPI, kể cả khi từ đó đã TOP1-10.
